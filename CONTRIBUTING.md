Для WebStorm:

Перейдите в Settings > Languages & Frameworks > JavaScript > Code Quality Tools и включите Prettier и ESLint.
В разделе Version Control настройте Before Commit проверки, чтобы автоматически запускать форматирование и линтинг перед коммитом.

Для Visual Studio:

Установите расширения Prettier и ESLint из Marketplace.
В настройках расширений включите автоматическое форматирование при сохранении файла.
